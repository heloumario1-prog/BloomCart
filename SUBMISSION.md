# BloomCart — Mario El Helou

## Portal-ready description

BloomCart is a responsive floral and gift boutique interface built with HTML5, CSS3 and vanilla JavaScript. Twelve sample products display local licensed photographs, categories, prices and ratings. A sticky header includes search, scroll-aware navigation and a cart badge. Choose quantity opens an accessible product dialog with a live total; confirmation adds the selected quantity and shows a pausable toast with View cart. The cart drawer supports quantity changes, removal, integer-cent totals and validated localStorage persistence. Search, category filters and price sorting work together. CSS Grid and Flexbox adapt the design to mobile and desktop. This frontend demo has no checkout or payment processing.
